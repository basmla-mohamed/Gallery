## ✦ ABOUT THE EXPERIENCE

**Gallery** is an interactive front-end project built to present images in a visually engaging layout.

Click on an image to open it in a popup and explore the selected picture in a larger view. JavaScript connects the gallery elements with the popup interaction, creating a more dynamic browsing experience.

## ⌁ THE INTERACTION

<div align="center">

| 01 — EXPLORE | 02 — SELECT | 03 — DISCOVER |
|:---:|:---:|:---:|
| Browse the images | Click your favorite | View it in the popup |

</div>

## ✧ FEATURES

- **Interactive Image Popup** — Open selected images in a dedicated popup.
- **Dynamic JavaScript** — Respond to user clicks and control the displayed image.
- **Visual Image Layout** — Present a collection of photos in an organized gallery.
- **Responsive Interface** — Designed to adapt to different screen sizes.
- **Focused Viewing Experience** — Give each selected image more attention.

## ⚡ UNDER THE HOOD

<div align="center">

<img src="https://skillicons.dev/icons?i=html,css,js&theme=dark" alt="HTML CSS JavaScript" />

**HTML5** — Organizes the gallery structure and image elements.

**CSS3** — Creates the visual layout, colors, spacing, and popup appearance.

**JavaScript** — Handles click events, DOM manipulation, and popup behavior.

## ⟡ WHAT I LEARNED

- Selecting HTML elements through the DOM.
- Handling user interactions with `addEventListener()`.
- Connecting images to popup elements.
- Updating the interface through JavaScript.
- Combining structure, styling, and functionality in one project.
